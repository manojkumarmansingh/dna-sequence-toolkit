# Changelog

All notable changes to this project are documented here.
The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and the project follows [semantic versioning](https://semver.org/).

## [Unreleased]

### Changed

- **CI now runs the web interface tests.** `tests/test_app.py` executes in a
  dedicated `web-app` job on Python 3.12 with `requirements.txt` and
  `requirements-dev.txt` installed, and the job fails if any app test is skipped.
  The core pytest matrix ignores the app module explicitly, so it stays free of
  Streamlit and pandas.

### Changed

- **Redesigned Streamlit interface**: deep navy, cyan and off-white palette,
  navy hero header with version and live status chips, a monospaced sequence
  workspace with Analyse, Load example and Clear, and responsive metric-card
  grids that reflow on mobile.
- **Seven analysis sections**: k-mer analysis moved out of Composition into its
  own section, with a frequency chart, a top-12 ranking and CSV export.
- **Samples and uploads** now load and analyse in one click instead of needing a
  second press of Analyse.
- Table downloads and the scientific-limitations panel are unchanged; every
  number still comes from `dna_toolkit.core`.

### Added

- **`tests/test_app.py`**: 14 tests driving the real script through Streamlit's
  `AppTest` harness (boot, load, analyse, every section, invalid input, Clear,
  multi-record FASTA). Skipped automatically when Streamlit is not installed.
- **`.streamlit/config.toml`** now pins the palette: navy primary, off-white
  canvas and a light slate sidebar.

## [0.2.0] - 2026-10-28

### Added

- **Streamlit web interface** (`app.py`) with six tabs (Overview, Composition,
  Transform, Translate, ORFs and Restriction sites), plus a sample sequence
  picker, paste box and FASTA upload.
- **Downloads** from the web app: CSV for tables, FASTA for sequences, JSON for
  the summary report.
- **Configurable ORF start codons** via `find_orfs(..., start_codons=...)`.
  Defaults to `ATG`, preserving previous behaviour.
- **Circular molecule mode** for restriction mapping via
  `find_restriction_sites(..., circular=True)`, which detects sites spanning the
  origin.
- **`examples/samples.py`**: short synthetic demo sequences used by the app.
- **Edge-case test suite** (`tests/test_edge_cases.py`): 36 tests covering
  boundaries, ambiguous bases, reverse-strand ORF coordinates, alternative start
  codons, circular digests and FASTA parsing.
- **Project banner** (`docs/banner.png`) generated by `docs/make_banner.py`.
- **Deployment guide** (`docs/DEPLOYMENT.md`).
- A CI job that installs the web dependencies and checks that `app.py` imports.

### Changed

- **FASTA parsing now validates every record** and reports the record name when
  a character is invalid, instead of failing later with a vague message.
- **README rewritten** with a feature table, workflow diagram, worked examples,
  a scientific limitations section and deployment steps.
- `gc_content`, `molecular_weight` and `translate` docstrings now state their
  assumptions explicitly (ambiguous-base handling, single-strand approximation,
  unknown codons rendered as `X`).
- `kmer_counts` documents that `k` longer than the sequence returns an empty
  mapping.

### Fixed

- Error messages for empty input and invalid characters now name the offending
  character and the allowed alphabet.

### Compatibility

The public API is unchanged. All new behaviour is opt-in through keyword
arguments with defaults that reproduce version 0.1.0 behaviour. The existing
25 tests pass without modification.

## [0.1.0] - 2026-10-25

### Added

- Initial release: composition and GC content, molecular weight, k-mer counts,
  reverse complement, transcription, translation, ORF finding, restriction-site
  mapping, FASTA parsing, a command-line interface and 25 unit tests.
